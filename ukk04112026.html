Student Grade Calculator

This is a dynamic web application capable of calculating a student's average grade, I hope this can be useful.

  • Calculating the grade using the following formula:

    • NA = (T *0,30)+(UTS *0,30)+(UAS *0,35)+(K *0,05)

    variable description:

    • NA = Final Grade
    • T = Assignment Grade
    • UTS = Midterm Exam Grade
    • UAS = Final Exam Grade
    • K = Attendance Grade
      • K = ((P-A)/P)*100
      • P = Total number of meetings
      • A = Number of absences

instructions of use

  1. Enter Student Name
  2. Enter Student Class
  3. Enter Student Attendance Number
  4. Enter Student Attendance(total attendance for one semester divided by 3)
  5. Enter Student Assignment Score
  6. Enter Student Midterm Score
  7. Enter Student Final Score
  8. press the submit button
  9. the results will be shown in the output section
